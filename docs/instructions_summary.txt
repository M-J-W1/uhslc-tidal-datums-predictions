0001: # UHSLC Tidal Datums and Predictions
0002: ## Purpose: 
0003: Update datums and tide predictions for all Fast Delivery and Research Quality hourly data that is served via ERDDAP.
0004: ## Protocol
0005: Learn best practices from legacy software, and make improvements where necessary. The deliverable is a Python script that may be ran in batch mode to cover groups of stations (all, FD, RQ, subsets, or individual stations).
0006: ### Output files
0007: Netcdf 
0008: One file per “station” record (e.g., 001, 001a, 001b, 001c would cover Pohnpei for FD and its three RQ versions)
0009: ### Reference frames and units
0010: Station zero
0011: GMT
0012: mm integer
0013: ### Epochs and data completion
0014: These are the primary epochs: NTDE_1983-2001, NTDE_2002-2020, IPCC-AR6_1995-2014.
0015: Attempt to calculate the datums and tidal harmonics/predictions for each of the primary 19-year epochs. However, this will be impossible for many “station” records, because of their data coverage. Use a 75% of hourly data for a completion criteria. If there is not 75% coverage for a particular epoch, skip it. For all records with at least 6 months of hourly data (>75% complete), make sure to define at least one epoch. That one epoch should be the most recent data, not to exceed 19 years. No station should have more than three epochs. Example: there will be one epoch for 001a (RQ), which will span 1969-05-09 to 1971-02-27.
0016: ### DatumsNote that since you do not have access to the switch elevations, it is okay to omit that. Otherwise, learn from the legacy software what datums to calculate and save.
0017: ### Tidal harmonics
0018: Harmonics should be calculated for each epoch. Include the tidal harmonics in the output file. Follow best practices learned from the legacy software, especially concerning treatment of the nodal cycle and trends.
0019: ### Tide predictions
0020: Tide predictions should be calculated for each set of harmonics. For FD stations: Output hourly predictions spanning the epoch start to 2100-12-31 23 hour. Also calculate minute predictions from each epoch end to 2030-12-31 23 hour (FD stations only). To reduce file sizes, only the times and heights of high/low daily tides from the minute predictions should be saved (review the legacy procedure). For the RQ stations: only calculate and save the hourly tide predictions spanning the available epochs (e.g., the prediction for 001a will cover the hours spanning 1969-05-09 to 1971-02-27).   
0021: ### Test stations Run tests on generate plots for the following stations, FD and all RQ versions: 001, 002, 003, and 007 (datums, hourly predictions/residuals, and minute predictions if application).
